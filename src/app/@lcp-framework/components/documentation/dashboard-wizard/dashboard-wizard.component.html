Introduction to Dashboard Static Wizard Builder

The "Dashboard Static Wizard Builder" is a powerful tool designed to enable users to create customizable widgets that can be added to any tab (wizard group) within the dashboard. This builder allows you to embed dynamic HTML content and fetch relevant information from a PostgreSQL database through a structured query. The flexibility provided by this tool makes it ideal for creating various dashboard components, such as charts, tables, and informative panels, that can be placed across different tabs or groups within the dashboard.

How to Use the Dashboard Static Wizard Builder

To create a widget using the Dashboard Static Wizard Builder, you need to define the content and the data source that will populate this content. The builder consists of two primary components: query_information and static_page_content.

  • Define the Entity:
    • Specify the name, type, and the wizard group where the widget will appear. For example, an error log panel might be created under the name "Error Logs" in the dashboard_wizard_builder_module.
  • Query Information:
    • This section defines how the data will be retrieved from the database. You specify the primary table, the columns to select, any joins needed, and conditions such as group_by, sort_columns, and limit_range. The example provided retrieves a count of error logs from the webservice_logs table, grouped by the id column.
  • Static Page Content:
    • This section contains the HTML structure and styling that will display the data fetched by the query. You can use placeholders (e.g., count) to embed dynamic data into your HTML content. The example provided creates a panel that shows the count of error logs.
  • Place the Widget:
    • Finally, configure the widget's placement on the dashboard by specifying the row, column, and order number.

Introduction to Dashboard Chart Widget

The Dashboard Chart Widget is a dynamic tool within the Dashboard Static Wizard Builder that allows users to create visually appealing and data-driven charts directly on their dashboard. Instead of using static HTML content, this widget leverages dashboard_wizard_options for configuring chart properties and styling, using ApexCharts as the charting library. The widget pulls data through a structured query and then visualizes it in the form of bar charts, line charts, pie charts, or other types.

How to Use the Dashboard Chart Widget

  • Define the Entity:
    • Start by specifying the name, type, and the wizard group where the chart will appear. The example provided is for an "Outlet Credit Limits Bar" chart.
  • Set Up Query Information:
    • Define the data that will be fetched from the database. This involves specifying the primary table, the columns to select, how to group the data, and how to sort it. In the example, the chart will display data grouped by the month of start_date and will show the quantity.
  • Design Chart Options:
    • Use the dashboard_wizard_options to customize the chart's appearance. You can define the type of chart, its height, colors, axes, tooltips, and other styling properties.
  • Place the Widget:
    • Finally, configure the widget's placement on the dashboard by specifying the number of rows and columns it will span, and its order number within the group.
