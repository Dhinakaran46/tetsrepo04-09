App Installation

The following process will be used to install admin dashboard using package manager.

  • Install Node.js: Please install the latest version of Node.js from https://nodejs.org
  • Extract main template: Extract the admin template site to your suitable directory or folder.
  • Access Command Prompt: Open Node.js command prompt.
    • Note:- The process mentioned below can also be executed with the system command prompt.
  • In CMD, Navigate to the location where the main folder is extracted.
  • Navigate to the root folder of the project where the package.json file exists.
  • Install node dependencies: Run npm install.
  • To run npm start.
    • Note:- When you run the above command, it will run the project in the browser automatically.
    • Note:- It will enable the auto-refresh function every time you save a file.
  • Run the command npm run build to build for production.
