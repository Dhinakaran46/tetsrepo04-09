Page Builder

Introduction

The Static Page Builder is a flexible and dynamic tool that allows developers to create customized web pages within the application using embedded HTML content and data fetched from a PostgreSQL database. By leveraging the Static Page Builder, users can easily design and implement pages that display real-time data, formatted and styled according to specific requirements.

This tool is particularly useful for creating dashboards, reports, or any page where the content needs to be dynamically generated based on the current data in the system. The Static Page Builder combines the power of HTML for designing the layout with SQL queries for retrieving and displaying data, making it a versatile solution for various use cases.

How to Create a Page Using Static Page Builder

To create a page using the Static Page Builder, follow these steps:

  • Define the Entity Information:
    • Entity Name: Choose a meaningful name for the entity, such as "User Grid."
    • Entity Type: Specify the type of entity, which could be a "Grid Builder Module."
  • Embed HTML Content
    • Use the static_page_content field to embed HTML code that defines the layout and structure of the page.
    • You can include placeholders in the HTML where dynamic data will be injected. These placeholders will be replaced with actual data retrieved from the database.
  • Configure Query Information:
    • Use the query_information field to define the SQL query that will fetch the necessary data from the database.
    • This includes specifying the tables, columns, join conditions, filters, and sorting criteria.
